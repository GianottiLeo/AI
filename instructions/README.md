# Instructions

> How to use this repository with AI assistant.

---

## Daily Workflow

### To Add Something

Just tell me naturally. Examples:

> "Task: Review Q1 reports #in-progress #work"

> "Quick note: Check if index exists before creating #sql"

> "Learning: CROSS APPLY lets you call a table-valued function per row #sql"

> "Snippet: [paste SQL code]  finds duplicate rows"

I'll reply with the exact edit and create a PR.

---

### To Find Something

> "What do I have on window functions?"

> "Show me my blocked tasks"

> "Summary of my SQL snippets"

I'll search and summarize.

---

### To Delete Something

> "Delete task: Old migration thing"

I'll create a PR removing it. You merge to confirm.

---

### To Update Something

> "Update learning SQL CTEs  add note about recursive limit"

I'll create a PR with the edit.
